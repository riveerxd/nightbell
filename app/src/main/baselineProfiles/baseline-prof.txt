# Pulse baseline profile — cold launch → dashboard.
#
# AGP merges every .txt in this directory into assets/dexopt/baseline.prof.
# ART then AOT-compiles the listed methods at install time instead of
# interpreting them on first run, which is where the bulk of a Compose app's
# cold-start cost lives.
#
# Syntax (HRF — human-readable format):
#   H  hot          — compile eagerly
#   S  startup      — touched during startup, lay out first in the dex
#   P  post-startup — touched shortly after
#   L…;             — a whole class (its <init> and <clinit>)
#
# THIS FILE IS HAND-AUTHORED. It covers the four flows the brief calls out
# (cold launch, list render, detail, setup) by naming the classes on those
# paths, which is the coarse-grained 80% of what a generated profile achieves.
# See HANDOFF.md → "Baseline profile" for how to replace it with a
# macrobenchmark-generated one, and why that is not wired up here.
#
# Rules are matched against *obfuscated* names after R8 unless
# `android.experimental.art-profile-r8-rewriting` is on; AGP 8.13 rewrites
# baseline profiles through the R8 mapping automatically, so the source names
# below are correct.
