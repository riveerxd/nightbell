Nightbell now confirms an outage in about a minute instead of half an hour. When you ask for more than one failure before an alert, the extra checks run 30 seconds apart rather than each waiting for the next scheduled check, so a blip is still ignored and a real outage still wakes you quickly. While the phone sleeps, that needs Nightbell exempt from battery optimisation or strict mode on.

Retry right away sits under Escalation, next to Failures before alerting, and is on for every monitor, including the ones you set up before this version. Turn it off to keep counting failures in scheduled checks. A failing monitor that has not alerted yet now says so on its card, for example "1 of 3 failures before it alerts". The retries stop when the phone goes offline, monitoring is paused or the monitor is muted, and GitHub repository monitors stay on their own schedule. While the phone is asleep, Android only lets them keep going if Nightbell is exempt from battery optimisation (Settings, Checks, Checker health) or strict mode is on; otherwise the leftover ones wait for the next scheduled check, as before.
