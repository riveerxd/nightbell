Nightbell now confirms an outage in about a minute instead of half an hour. When you ask for more than one failure before an alert, the extra checks run 30 seconds apart rather than each waiting for the next scheduled check, so a blip is still ignored and a real outage still wakes you quickly.

Retry right away sits under Escalation, next to Failures before alerting, and is on for every monitor, including the ones you set up before this version. Turn it off to keep counting failures in scheduled checks. A failing monitor that has not alerted yet now says so on its card, for example "1 of 3 failures, re-checking every 30s". The retries stop when the phone goes offline or monitoring is paused, and GitHub repository monitors stay on their own schedule. Reported in issue 20.
